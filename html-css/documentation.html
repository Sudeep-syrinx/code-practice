Introduction to BuilderHub

BuilderHub is a platform that tracks your coding progress across multiple programming languages. Every line of code you write counts toward your global ranking.

What is BuilderHub?

BuilderHub monitors your GitHub repositories and counts the lines of code you add to your main branch each week. It supports Python, JavaScript, Java, C++, HTML, CSS, and more.

The platform is designed for students and developers who want to build consistent coding habits and compete on leaderboards.

Key Features

  • Multi-Language Support: Code in any language. All lines count equally.
  • Weekly Tracking: Your progress is measured every week since September.
  • Transparent Rules: Clear guidelines on what counts and what doesn't.
  • Badges & Achievements: Earn badges for consistency and milestones.
  • Campus Leaderboards: Compete with peers at your university.

What Counts?

✅ Counted

  • Code you write in any programming language
  • Python, Java, C++, JavaScript, HTML, CSS
  • Code cells in Jupyter notebooks

❌ Not Counted

  • Folders like node_modules and build
  • Lock files and minified files
  • Data files (.json, .csv, .sql)
  • README, documentation, .txt files
  • Libraries you add (Bootstrap, etc.)

Quick Example

Here's a simple Python function that counts toward your total:

def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        need = target - n
        if need in seen:
            return [seen[need], i]
        seen[n] = i
    return []

This 9-line function will add 9 lines to your weekly count when pushed to your main branch.
